# v1: 경제지표 예측 → OLS로 고용률 예측 (실패)

## 시도

1. 상관·VIF로 고른 4개 변수(GDP, KOSPI, DOLLAR, RATE)를 **Prophet으로 각각 2023년까지 예측** (`prophet_forecast.py`)
2. 2010~2022년 데이터로 학습한 **OLS 회귀식에 예측된 지표를 넣어** 2023년 고용률 예측 (`ols_predict.py`)

## 결과

표준화 값 기준 MAE 1.66 (고용률 표준편차의 1.7배 수준 오차). 예측값이 2023년 실제 상승 추세를 전혀 따라가지 못함 → `final_result_comparison.csv`

## 원인 분석

- **오차 누적**: 경제지표 예측 오차 + 회귀 오차가 겹침
- **시계열 특성 무시**: OLS는 계절성·추세를 반영하지 못함
- **변수 선택 기준 부족**: 상관계수 상위 변수만 사용, 유의성 검증 없음

## 개선 (최종 모델)

- 변수 선택에 **p-value 검증** 추가 → 7개 변수
- 고용률 자체를 **Prophet(추세·계절성) + 경제지표 Regressor**로 모델링
- 결과: 2025년 백테스트 MAE **0.37%p**
